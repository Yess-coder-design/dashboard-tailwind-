# Dashboard Tailwind CSS

Dashboard moderno desarrollado con **HTML y Tailwind CSS**, creado como práctica de desarrollo frontend y recreación de una interfaz visual a partir de un diseño de referencia.

## 🚀 Tecnologías

* HTML5
* Tailwind CSS


## 📌 Descripción

El proyecto consiste en la creación de un dashboard utilizando **Tailwind CSS** para construir una interfaz moderna, limpia y responsiva.

El objetivo principal es practicar:

* Diseño de interfaces con Tailwind CSS.
* Uso de clases utilitarias.
* Distribución de elementos mediante Flexbox y Grid.
* Organización de componentes visuales.
* Maquetación frontend a partir de un diseño de referencia.

## 💻 Instalación

Clona el repositorio:

```bash
git clone https://github.com/Yess-coder-design/dashboard-tailwind-.git
```

Entra al proyecto:

```bash
cd dashboard-tailwind-
```

Abre `dashboard.html` en tu navegador.

## 🎨 Características
